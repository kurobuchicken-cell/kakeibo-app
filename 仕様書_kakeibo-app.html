仕様書：kakeibo-app（レシート読み込み家計簿Webアプリ）

作成日: 2026-06-22

1. 概要

レシート画像をアップロードすると、Claude API（画像解析）が自動で日付・店舗名・商品・金額・カテゴリを読み取り、家計簿として一覧・集計・グラフ表示する個人向けWebアプリ。データはサーバーには保存せず、ブラウザの localStorage にのみ永続化する。

2. 技術スタック

層技術
フロントエンドReact 18 + Vite 5
バックエンドNode.js + Express 4
AI（画像解析）Anthropic Claude API（モデル: claude-haiku-4-5-20251001）
グラフChart.js 4 + react-chartjs-2
ファイルアップロードmulter（メモリストレージ、10MB上限）
データ永続化ブラウザ localStorage（サーバー側DBなし）

3. システム構成

ブラウザ (http://localhost:5173, Vite Dev Server)
   │  fetch('/api/analyze-receipt')  ※Viteプロキシ経由
   ▼
Express サーバー (http://localhost:3001)
   │  画像Base64化 → Claude API呼び出し
   ▼
Anthropic Claude API (claude-haiku-4-5-20251001)
   │  JSON形式でレシート解析結果を返却
   ▼
Express サーバー → ブラウザへJSON返却 → localStorageに保存

APIキーはサーバー側の .env（プロジェクトルート）でのみ管理し、ブラウザには一切露出しない。Vite の /api プロキシ設定（client/vite.config.js）により、フロントエンドはCORSなしでバックエンドにアクセスする。

5. 画面構成（3タブ構成）

5.1 アップロードタブ

  • ドラッグ＆ドロップ、またはクリックでファイル選択（JPG/PNG/WEBP/GIF、最大10MB）
  • 選択直後にプレビュー画像を表示し、解析中はローディングスピナーを表示
  • 解析成功時は商品一覧（カテゴリバッジ付き）・合計金額を表示し、自動で一覧タブにデータを追加
  • 失敗時はエラーメッセージを表示

5.2 一覧タブ

  • 登録済みレシートを新しい順にカード表示（店舗名・日付・合計金額・商品テーブル）
  • レシート単位の削除、全件削除（確認ダイアログあり）
  • データが0件の場合は空状態メッセージを表示

5.3 グラフタブ

  • サマリーカード：今月の支出合計／登録レシート数／累計支出
  • 今月のカテゴリ別内訳（横棒グラフ形式の内訳バー）
  • カテゴリ別支出（円グラフ、全期間）
  • 月別支出（棒グラフ、直近6ヶ月）

カテゴリ分類はClaude APIへのプロンプト内でこの7種類に固定するよう指示している。商品単位でカテゴリが付与される（レシート単位ではない）。

7. API仕様

7.1 POST /api/analyze-receipt

項目内容
リクエストmultipart/form-data、フィールド名 image（画像ファイル、最大10MB）
処理画像をBase64化し、Claude API（claude-haiku-4-5-20251001）に解析プロンプトと共に送信。レスポンス文字列から正規表現でJSON部分を抽出してパース
正常レスポンス200 OK、下記レシートJSON
異常レスポンス400: 画像ファイル未指定 / 500: 解析失敗（JSON抽出不可・Claude API例外等）、{ error, detail }

7.2 GET /api/health

サーバー起動確認用。{ status: "ok", model: "claude-haiku-4-5-20251001" } を返す。

8. データモデル

8.1 Claude解析結果（APIレスポンス）

{
  "date": "YYYY-MM-DD",
  "store": "店舗名",
  "items": [
    { "name": "商品名", "price": 198, "category": "食費" }
  ],
  "total": 1280
}

8.2 localStorage保存形式（キー: kakeibo-receipts）

上記レスポンスに以下を付加した配列を、新しい順（先頭が最新）で保存する。

{
  ...（8.1のフィールド）,
  "id": "Date.now()の文字列",
  "registeredAt": "ISO8601タイムスタンプ"
}

9. レシート解析プロンプトの仕様（要点）

  • JSON以外のテキスト（コードブロック・説明文）を含めないよう明示的に指示
  • 日付が読み取れない場合はサーバーのリクエスト時点の日付（今日）を使用するよう指示
  • 価格は税込み金額を使用
  • カテゴリは上記7種類から選択させ、自由記述を許可しない

10. セットアップ・起動

cp .env.example .env        # ANTHROPIC_API_KEY を設定
npm run install:all         # ルート/server/client の依存を一括インストール
npm run dev                  # サーバー(3001)・クライアント(5173)を同時起動
環境変数説明デフォルト
ANTHROPIC_API_KEYAnthropic APIキー必須・未設定だと解析失敗
PORTバックエンドサーバーのポート3001

11. 非機能要件・制約

  • 画像アップロードサイズ上限: 10MB（multerのファイルサイズ制限）
  • CORS許可オリジン: http://localhost:5173, http://localhost:3000（サーバー側でホワイトリスト指定）
  • データベース・サーバー側永続化なし。全データはブラウザのlocalStorageに保存されるため、ブラウザ・端末をまたいだ共有はできない
  • APIキーはサーバー側の.envのみで管理し、Gitにコミットしない（.gitignore対象）
